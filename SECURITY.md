# Security and safety reports

For sensitive reports, use GitHub's private vulnerability reporting when available on this repository. If unavailable, open an issue asking for a private contact without disclosing exploit details, credentials, device identifiers or firmware contents.

For ordinary rendering or stability bugs, provide a redacted issue using the compatibility and testing guides. Include build identity and reproduction steps, and distinguish audio behavior from browser behavior.

Only the exact documented 1.44 source image is accepted. This independent experimental project provides no guaranteed rescue path or manufacturer support. Do not treat a successful build, checksum or normal update as proof that every device can recover from an application failure.

# Evidence

`release-v1.json` is the curated public record. It separates owner-reported hardware acceptance from local tests and the uninstalled final label package.

Other reports generated during research stay local and are ignored by Git. They can contain USB identifiers, track names, local paths or packet metadata. Never upload them wholesale to an issue or release.

Public test counts are reported separately from the original 384-test run with private firmware and owner fixtures. Skipped private checks are not passing checks.
